### 5.2 The current look (homepage)

The site should feel like a top agency / modern AI engineering company, not a course landing page and not a neon gaming brand.

- **Scale:** Lando-size, not compact (Replit-style) sections. Every section after the hero uses the same large type and spacing (serif headlines 2.4–4.8rem, section padding 4.5–8rem). Big type does nothing for SEO by itself; the words in the HTML do.
- **Surfaces:** black stage `#0A0B07` → olive `#232719` (where the hero's scroll ends, then the statement and "How we work") → light blueprint surface `#F4F6F1` with near-black text `#101114` → dark Solutions gallery `#11150F`.
- **Accent (confirmed by the user, 14 Nov):** brand lime `#AED534` across the whole public site. `--neon` aliases `--lime`; statement words/bars, gallery, buttons, navigation, footer, inline SVG, canvas and WebGL effects share it. Hover/highlight tint is `#C3E651`; translucent effects retain their opacity. On light backgrounds, existing olive/ink emphasis remains for contrast.
- **Type (site-wide statement system, explicit user request 2 Nov):** the large paragraph is the reference for every public page. Mona Sans is the primary family for headings, body copy, navigation, forms, cards, labels, SVG text and canvas lettering. Existing Artificia Statement Sans (660 / width 93) remains the fixed display face, preserving the statement exactly; new Artificia Sans variable (200-900 / width 93, 68,604 bytes) supplies readable body/UI weights. Bodoni Moda / Artificia Statement Serif (500, roman) provides the same accents, retaining each component's existing highlighter treatment. Since 13 Nov its subset (`statement-serif.woff2`) also maps the liga lookup (fi, fl, ff) to `rlig`: browsers drop liga under letter-spacing, which made the "f" hook collide with the "i" in "Artificia"; keep this if the file is re-subset. Metadata uses Mona Sans too. This supersedes the older public Roboto-only rule; separately styled admin retains its operational typography. All fonts remain self-hosted/OFL-licensed.
- **Button corners (user refinement, 12 Nov):** every public button and button-like link uses the same softly rounded 12px corners, via `--button-radius: 12px` in site.css. The user asked for less roundness after reviewing the full pills. This includes masthead, hero, enquiry form, carousel/playback/dialog controls, solution chips, WhatsApp and footer; conflicting component radii are removed. The footer action sits separately 12px above the legal strip, without the old flared SVG ends. Other surfaces retain their component-specific shapes.
- **Masthead (user, 4 Nov):** every page, at every width, uses the homepage's masthead pattern: logo, Enquire, and an outlined "☰ MENU" button that opens the full-page numbered menu (since 14 Nov: Home, Masterclass, Corporate training, Solutions, About, Careers, Contact; rows fill the whole open screen, type sized to the viewport, desktop up to 4.5rem, phones up to 2rem). No horizontal desktop nav. The page you are on is neon (#AED534) in the menu; hover is neon too. On the dark-hero pages (homepage stage, Solutions, Masterclass) there is no black bar: the masthead floats transparent over the hero and turns solid (#15160F) once the hero has scrolled away (phones: after 40px). Light-topped pages (Contact, legal, etc.) keep the solid bar, because the logo's white lettering would vanish on paper. The testimonial fan's cards and the footer's neon frame are rounded on purpose, because the reference's composition depends on it.
- **Logo:** always the real image (`public/assets/img/artificia-logo.png`, tagline "AI-Driven, Future-Focused.", lime figure #AED534). Never redrawn, never recoloured, never a text wordmark.
- **Imagery:** the robot appears **in the hero and, at the user's request (30 Oct), in the Before AI / With AI section**, and in the footer (2 Nov: the user requested a matching regenerated cutout with an intrinsic neon tie). The footer figure is the logo's robot-in-a-suit character, with the hero's head as an identity reference. Nowhere else (the blueprint warns against "stock robot imagery on every section"). Prefer real workflow screenshots, diagrams and code-drawn SVG. Images have been made in Canva and the built-in image-generation tool; the current footer cutout uses the built-in tool. Higgsfield and Gamma were out of credits.
- **Motion:** purposeful, always showing a process (pulses along a pipeline, a live-run panel, scan lines). Scoped GSAP/CSS reveals and WebGL for the hero and visible contour surfaces. Shared contour renderers cap active WebGL contexts at 12; inner-page section canvases acquire contexts near the viewport and release them off screen. Context loss falls back to static contours or the CSS wave, preserving the original ground. The work gallery canvas is capped at 30fps and pauses off screen. Everything is still under reduced motion.
- **Copy style:** minimal. The user wants the design to lead: short headline, no paragraph in the hero. Plain, factual English with short sentences (many readers' first language is Gujarati or Hindi).
